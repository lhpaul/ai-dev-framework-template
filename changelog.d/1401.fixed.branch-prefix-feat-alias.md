- **`feat/` branches are now recognised as `feature/`** (#1401): `branch_prefix` resolved `feat/*` to `unknown`, so such a branch was never deleted by `post-merge-cleanup.sh`, received no reviewer from `reviewer_for_branch` (no code review from the loop), and took the wrong repository context and `NEXT_ACTION` in `workflow-next-action.sh`. `feat/` is now an alias of `feature/` in `workflow-lib.sh`, so every consumer is fixed at once. `chore/`, `docs/`, `cursor/` and `haystack/` stay `unknown` by design; the change only affects future cleanups and deletes nothing retroactively.
