- **Post-merge cleanup no longer treats pull requests as issues to close**
  (#2021): a closing keyword in a merged PR's title, body or commit messages
  that points at a pull request (for example prose that pairs a closing
  keyword with an old PR number) is now skipped with a NOTE naming it. The
  merge-session projection no longer plans tracker or close steps for it.
  If the issue or pull-request kind cannot be determined, cleanup fails
  closed. Real issue references and Linear trackers behave as before.
