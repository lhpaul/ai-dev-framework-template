- **`workflow-shell-snippet-lint.py` no longer reports success after examining nothing** (#1658): the linter now prints an `examined=N files, M fences` summary on every run, and exits non-zero when it had nothing to examine — an empty diff, or an `--input` file that is a path list rather than a unified diff. Previously both cases exited 0 in silence, which read as a clean result: on one pull request that false pass hid a real WS002 finding. A well-formed diff that touches no in-scope guidance file still exits 0, and says so. Use `--allow-empty` where an empty diff is genuinely expected.
