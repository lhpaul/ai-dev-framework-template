- **`post-merge-cleanup.sh` no longer applies a product-repo PR's bare closing keywords to the hub tracker** — in `workflow_hub` mode, `Closes #NNN` / `Fixes #NNN` / `Resolves #NNN` in a product-repository PR are numbered in the product repo, but cleanup closed and status-updated the hub issue with the same number. Bare references from a product PR are now skipped with a visible `NOTE:`; only hub-qualified references (`Closes <hub-owner>/<hub-repo>#NNN`) are honoured, and the close comment names the product PR as `owner/repo#N`. If the hub repository cannot be resolved, cleanup warns and applies no PR-body references. Covers the team-prefixed override, the branch-derived extra-closes, and the no-identifier fallback paths.
