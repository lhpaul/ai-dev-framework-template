- **Open framework-item reads are complete and repository-scoped** (#1804):
  `list_open_framework_items.sh` and `list_open_workflow_type_issues` no longer
  stop at 1,000 open issues or 1,000 project items — they keep reading until
  the list is complete, up to 64,000 records, and report
  `issue_list_truncated` / `item_list_truncated` instead of a partial list past
  that bound. Project items now match open issues by repository and number,
  so another repository's item with the same number on a shared organization
  board, or an item that names no repository, is no longer reported as one of
  this repository's open items.
