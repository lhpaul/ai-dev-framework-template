- **Reviewer loop no longer warns that creating an existing `reviewer-failed` label failed** (#1764): `ensure_reviewer_failed_label_exists()` probed the label with `gh label view`, which does not exist, so every run fell through to a redundant `gh label create` and logged a misleading `WARN: failed to create reviewer-failed label`. It now probes with `gh api repos/{owner}/{repo}/labels/reviewer-failed`, creates the label only on HTTP 404, skips the create with an explicit "could not determine" WARN on any other probe failure, and reports a real `gh label create` failure with gh's own message. The test `gh` mock now rejects `gh label` verbs the real CLI lacks, so an invalid verb can no longer pass.
