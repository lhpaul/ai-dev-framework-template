- **Linear epic parents use `In Progress`; children keep the fine-grained stages** (#1447): the Linear integration guide (`integrations/linear.md`), `tracker-status-mapping.md`, and Protocol 95 (`/run-epic`) now document `In Progress` as an out-of-band, epic-only Linear status, like `Cancelled`. When `/run-epic` starts mutating work and the epic is still `Backlog` or `Todo`, the orchestrator sets it to `In Progress` once through the Linear MCP bridge. Children keep the canonical chain, the epic no longer walks `Writing Spec` → `In Development` → `Merged` each time a child does, and it moves to `Released` only after the epic outcome is accepted in production. The canonical vocabulary is unchanged: `tracker-status-for.sh` still never resolves `In Progress`, and GitHub Projects boards are unaffected.
