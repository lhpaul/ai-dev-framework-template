- **Review gates weigh test-scope proportionality, not literal conformance** (#1785): a delta between a plan's projected test scaffolding and what an implementation ships is blocking only when the reviewer names the specific coverage the removed items provided and the defect class that now escapes, unless the plan marked the reduced enumeration `**Binding enumeration**`, which stays blocking regardless of a stated harm. Implementers record a Test-Scope Deviation Record that the gate evaluates whenever delivered test scaffolding removes at least one item an indicative plan enumeration projected -- including a net-even or net-larger substitution that drops a projected case, not only a smaller total -- and plan enumerations are indicative unless explicitly marked binding, in which case a removal is restored, or the plan is amended and a record written if a coverage-equivalent deviation still remains, and plan review gains an advisory, never-blocking signal when projected test scaffolding outweighs the deliverable it protects. Review of production-code correctness and of third-party reviewer output is unchanged.
