- **An agent can no longer silently edit a sibling's pull request in a parallel wave** (#1444): the new `scripts/development-workflow/pr-ownership-guard.sh` resolves a PR's head branch and exits `0` only when it matches the item's branch, refusing a mismatched number (`RESULT=not_owned`) and failing closed when the PR or the current branch cannot be resolved. Protocols 01, 02, and 03 now require it before every `gh pr edit`, `gh pr comment`, `gh pr ready`, or label change by number. Protocols 90 and 91 give each parallel agent a private scratch directory with collision-proof filenames such as `pr-body-<item>-<pid>.md`, and ask for review-gate evidence to be mirrored as a PR comment, since a PR description can be overwritten silently.
