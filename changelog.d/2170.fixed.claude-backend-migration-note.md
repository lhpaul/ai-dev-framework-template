- **0.51.0 Claude backend migration note** (#2170): the `sync-manifest.yaml` note and `local-ai-reviewer.md` now tell a consumer to set `review.local_ai_reviewer.backend: claude` only when its local patch made Claude the repository default (or it wants that default now). A consumer whose patch only added a Claude backend while Codex stayed the default leaves the shared key unset and keeps exporting `LOCAL_AI_REVIEWER_BACKEND=claude`. This corrects the 0.51.0 changelog sentence that told every consumer with a locally patched Claude backend to set the key.
