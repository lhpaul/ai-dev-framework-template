- **CodeRabbit stale-findings fallback skips resolved threads** (#1578): when CodeRabbit never reviews the current HEAD (for example, after it exhausts its rate-limit retries), `pr-review-loop.sh` scans CodeRabbit's existing inline comments as a fallback. That scan now leaves out any comment whose GitHub review thread is resolved. Previously a resolved finding that still showed its original Major or Critical badge counted as blocking. The loop then reported `RESULT=needs_fixes REASON=stale_findings` with zero unresolved threads and sent a fixer with nothing to fix. With no unresolved threads left, an exhausted rate limit now escalates as `REASON=rate_limit_max_retries`. If the thread state can't be read, the fallback still counts the comment, so an unreadable state never produces a false clean.
