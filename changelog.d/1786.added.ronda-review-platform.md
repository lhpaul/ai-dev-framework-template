- **`ronda` is now a supported `pr-review-loop.sh` GitHub reviewer platform** (#1786): Ronda is a GitHub-facing bot that posts a pull-request review plus a single `Ronda review` check run per head SHA, created exactly once, at the end of a pass, already `completed` — there is deliberately no `in_progress` write. `run_ronda_review` polls the check-runs API scoped to the PR's current head SHA (re-resolved on every poll, so a new commit naturally supersedes an in-flight pass) and treats absence of the check run as "not finished yet," never as "no review configured" or "clean." A `success` conclusion reports `RESULT=clean`; `failure`/`action_required` reports `RESULT=needs_fixes` with the blocking count read from Ronda's inline review comments (floored to 1); any other terminal conclusion, a `gh`/`jq` fetch failure, or an unresolved head SHA escalates. `ronda` can now be named in `review.on_draft.github` / `review.on_ready.github`, with `RONDA_BOT_LOGIN` / `RONDA_CHECK_NAME` overrides documented in `.ai-dev-workflow.yaml`.
