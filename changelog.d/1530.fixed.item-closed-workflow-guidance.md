- **GitHub Projects setup no longer recommends a close-to-`Merged` built-in workflow** (#1530): the GitHub Projects integration guide (`integrations/github-projects.md` §2.1) now recommends disabling the built-in "item closed" Status update, or pointing it at `Cancelled`, instead of setting `Merged`. The built-in workflow applies one Status to every close and cannot tell delivered work from an issue closed as not planned, so the old recommendation made cancelled items read as delivered on the board. The merge path is unchanged: the repository's merge automation and `post-merge-cleanup.sh` still set `Merged` explicitly after closing implementation issues.
