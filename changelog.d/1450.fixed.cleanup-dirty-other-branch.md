- **Post-merge cleanup with a dirty unrelated checkout** (#1450): `post-merge-cleanup.sh` no longer aborts on a base-branch checkout overwrite error when the current checkout is on a different branch with uncommitted tracked changes. It fast-forwards the base ref without checking it out (reported as `BASE_CHECKOUT_SKIPPED=dirty_other_branch`), leaves the caller's branch and edits untouched, and still deletes the merged local and remote branch.
