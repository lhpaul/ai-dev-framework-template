- **Step 7a decides reviewer reachability from capability, not runner identity** (#1495): the internal review gate used to consult a fixed table that called the Codex reviewer unreachable whenever a different runner was driving the gate, even on a machine where the Codex command was installed and about to be used successfully by the next gate in the same pipeline — and since the shipped configuration named Codex as the only internal reviewer, the gate found nothing to dispatch and blocked. The gate now probes each configured reviewer against the environment it is actually running in, under a fixed ten-second ceiling, and reports each one as Reachable, Unreachable with one of four named reasons and a remedy, or Excluded by override. The shipped default reviewer list changed so that whichever supported runner drives the gate, that runner's own reviewer is reachable by construction, and the Codex GitHub App review is supported as a hosted-service reviewer whose availability uses a bounded repository-activity proxy, with its limitations and dispatch-time failure handling documented. CodeRabbit enablement validates the whole configuration using the existing PyYAML dependency, rejects invalid documents and duplicate keys, and accepts standard typed boolean spellings while preserving valid YAML collections and merge defaults. Configuration and missing-parser errors provide actionable repair guidance. Inconclusive remedies target the failing probe, and retired local override backups stay ignored in the template; downstream retirement guidance requires the same ignore rule. Reserved percent-prefixed YAML nodes and malformed plain scalars anywhere in workflow review configuration block dispatch, and cancellation gives the Linux supervisor bounded time to terminate and reap detached probes. Workflow configuration flow values validate nested delimiters and trailing content while preserving quoted delimiters and valid block scalars. JSON validation and decoding run under the same bounded watchdog as runtime and hosted probes. Key/value output renders decoded C0/C1 controls as visible escapes to prevent terminal control sequences while preserving valid YAML values. Raw YAML input rejects non-printable characters before stripping comments while retaining supported quoted escapes. Flow validation rejects comment indicators at node starts while preserving quoted and interior hashes. Strict comment parsing keeps quotes inside plain scalars literal and preserves their trailing comments. Strict YAML node indicators recognize both space and tab separators. Strict YAML separation preserves Unicode whitespace as scalar content instead of discarding it or starting comments. Strict null and boolean recognition preserves noncanonical mixed-case strings, preventing accidental policy defaults or reviewer fallback; legacy parsing remains unchanged.
