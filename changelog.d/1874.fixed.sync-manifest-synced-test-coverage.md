- **Sync ships the files synced tests read** (#1874): `sync-manifest.yaml` now
  lists the framework CI workflows (`pr-policy.yml`, `shellcheck.yml`,
  `workflow-tests.yml`, `markdown-lint.yml`, `closing-keyword-scope.yml`), the
  PR-Agent and Claude Code Action reviewer workflows, and the Haystack `hooks/`
  as special handling, plus the two protocol-level runbooks a synced test
  asserts on. A new `required_additions` section names additive updates
  project-owned files need, starting with `push_verification_failed` in a
  declared `guardrails.stop_conditions` list. The new
  `check-sync-manifest-coverage.py` reports any file a synced test reads that
  the manifest does not ship. The template's CI runs it, and `/sync-template`
  Step 0.5 runs it as part of the pre-flight diagnostic, so missing additions
  show up as Required additive updates. The guidance check in
  `test-framework-mode-type-routing.sh` now asserts on the wording of the
  project-owned `AGENTS.md`, `CLAUDE.md`, and `GEMINI.md` only in the template.
