- **Tracker Status: an unknown status names the valid options, and one mapping ties readiness to Status** (#1564). Before this change, `update_tracker_status_best_effort` warned "could not resolve Status field or option" and did nothing. The caller was never told which values the board accepts. Nothing defined which Status a readiness label sets either, so runners given the same instruction left the board in different states.
  - **Unknown status**: the helper now reports an unreadable Status field separately from an option the board lacks. The warning lists the board's actual options and prints a machine-readable `TRACKER_STATUS_UNRESOLVED issue=… requested='…' reason=… valid_options='…'` line.
  - **Strict mode**: when `WORKFLOW_TRACKER_STATUS_STRICT=true`, an option the board lacks is a non-zero failure. An unreadable field stays best-effort, because that failure can be transient. Default callers see no behavior change.
  - **Canonical mapping**: `docs/workflow/development-workflow/tracker-status-mapping.md` is now the only definition of the Status vocabulary and the event-to-Status mapping (`dispatch`, `ready-for-human-review`, `merged`, `released`). The readiness labels that leave Status unchanged are listed there too. Its machine-readable copy is `workflow_tracker_status_for_event` in `workflow-lib.sh`.
  - **Resolver**: the new `scripts/development-workflow/tracker-status-for.sh` looks up the Status for an event and branch. With `--apply`, it also writes that Status in strict mode and exits `3` when the board lacks the option.
  - **Protocols**: Protocols 90 and 91 (Step 2, Step 8b, and Step 10), Protocols 01, 02, 03, and 92, and the GitHub Projects and Linear integration guides now point to the mapping page instead of keeping their own copies. An unresolved Status in an orchestrated run stops under `missing_tracker_context` and is not silently skipped.
  - **Checks**: `check-tracker-merge-mapping.sh` reads its expected values from the same mapping. The new `test-tracker-status-mapping.sh` fails when the mapping page and the function disagree.
