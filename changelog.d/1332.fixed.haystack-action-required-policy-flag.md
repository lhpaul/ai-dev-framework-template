- **Haystack guide explains `action_required` with a positive rating** (#1332): the Haystack integration guide (`integrations/haystack.md`, Operating model) now says that a `Haystack / Review` check run concluding `action_required` with a positive rating and zero findings is a review-policy request for a human look, not a code-finding failure. It describes how the reviewer loop treats it: `RESULT=clean` when the check-run summary reports `**Findings:** 0`, a fail-closed `needs_fixes` when the findings count can't be parsed, and `haystack (needs-review: policy)` with `disposition=policy-human-review` on the CLI path. Operators no longer mistake the flag for a failed check.
