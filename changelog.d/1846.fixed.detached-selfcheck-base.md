- **Self-check accepts the detached worktree left by merged cleanup** (#1846): `post-merge-cleanup.sh` detaches the caller's own worktree onto the updated base instead of deleting the branch it stands on, so `git rev-parse --abbrev-ref HEAD` reports `HEAD` and `item-completion-self-check.sh` flagged `repository.branch` and `workspace.worktrees` as discrepancies on a fully merged, correctly cleaned-up item. With `--pr` and `--expected-base`, a detached HEAD now counts as returned to the expected base when the PR is merged and HEAD equals or descends from the base tip (`refs/heads/<base>`, else `refs/remotes/origin/<base>`); the row evidence names the tip and the merged PR. Unmerged PRs, a HEAD behind the base, a missing base, an unreadable PR state and runs without `--pr` keep the discrepancy. Regression coverage in `tests/test-item-completion-self-check.sh`.
