- **Reviewer loop fails fast when `codex-github` has no local reviewer** (#1817): when `codex-github` is configured but `local-ai-reviewer` is in neither `review.on_draft.github` nor `review.on_ready.github`, the expensive-reviewer gate can never pass. `pr-review-loop.sh` used to defer anyway and report `RESULT=needs_fixes` / `expensive_gate_deferred` with zero findings and zero threads until the deferral cap. The gate now reports `EXPENSIVE_GATE_RESULT=config_error`, and the loop escalates on the first evaluation with `REASON=expensive_gate_local_reviewer_not_configured`. It runs no deferral rounds, spends no deferral budget and, in the ready phase, does not mark the PR ready. The loop summary names the fix: add `local-ai-reviewer`, drop the expensive platform, or set `PR_REVIEW_LOOP_FORCE_EXPENSIVE_REVIEWERS=1` for a justified one-off run. The force override is unchanged. The reviewer-platform configuration guide, the Codex GitHub integration guide and Protocol 93 now document the companion requirement.
