- **`print_kv_escaped` is linear on macOS bash 3.2** (#1539): `workflow-lib.sh` escaped the whole value with repeated `${var//pattern/replacement}` passes, which bash 3.2 runs in quadratic time — a 24 KB value took about 28 seconds and 117 KB did not finish in two minutes. A value longer than 512 bytes is now streamed in 512-byte chunks, each escaped and printed as it is read, never splitting a UTF-8 C1 pair; 117 KB takes well under a second and 3.7 MB about ten seconds. The output stays byte-identical, including the `\xNN` and `\u00NN` control escapes, and the function signature and its callers are unchanged. Regression coverage in `tests/test-workflow-lib-print-kv-escaped.sh` checks byte equivalence with the previous implementation, a single-line round trip, a runtime bound and an 8x-input scaling bound under every available bash (including `/bin/bash` 3.2), a per-pass size bound, and parity with the `workflow_diagnostic_kv_escaped` emitter used for `BLOCKING_<n>_BODY`.
