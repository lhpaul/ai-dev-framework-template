- **ShellCheck no longer needs ~17 GB on the pr-review-loop test suite** (#1876):
  `test-pr-review-loop.sh` (24.6k lines) is split into ten suites that share
  one harness library, `tests/lib/pr-review-loop-harness.sh`. The largest now
  lints in under 1 GB in a few seconds, and CI runs the suites in parallel
  shards instead of as one long job. The `ShellCheck` workflow runs one
  process per file, so peak memory is bounded by the largest file, and has a
  job timeout. Every pr-review-loop suite is capped in size by a test, so the
  harness cannot grow back into one file. ShellCheck 0.11.0's SC2034 findings
  in `test-local-ai-reviewer-pr-review-loop-dispatch.sh` are fixed. Private
  repositories, whose smaller runners were shut down mid-lint, can lint these
  files again.
