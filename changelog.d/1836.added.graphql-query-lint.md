- **Repo-wide lint for `gh api graphql` query literals** — `scripts/lint/lint-graphql-query-literals.py` scans every `.sh` file under `scripts/` (excluding `tests/` fixtures) for `gh api graphql` query literals with correctly nested braces, brackets, and parens, skipping GraphQL string values and `#` comments and handling bash string concatenation. This generalizes the single-file check added for #1828 (an unbalanced query in `apply-readiness-labels.sh` that the mocked test suite could not catch) into a CI gate (`.github/workflows/shellcheck.yml`) that runs on every `scripts/**/*.sh` change. `docs/best-practices/3-testing.md` and `REVIEW.md` now also require a one-time live validation of every new or changed query against a real GitHub repository/PR, since a delimiter-balance pass cannot detect an unknown field or wrong argument type.
