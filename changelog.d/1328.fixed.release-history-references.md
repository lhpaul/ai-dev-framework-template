- **Release stamping of historical references** (#1328): release cleanup with `--from-changelog` no longer stamps an issue that a release section cites only as context. For GitHub trackers, a reference that an earlier release section also cites is checked on GitHub and left out of scope when the issue is closed with an earlier release milestone, reported as `RELEASE_SCOPE_SKIPPED`. Every other case keeps the issue in scope, a failed check is reported as `RELEASE_SCOPE_HISTORY_UNVERIFIED`, and explicit `--issue` / `--issues` are never filtered.
