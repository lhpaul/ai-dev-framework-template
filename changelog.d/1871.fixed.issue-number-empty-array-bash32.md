- **`extract_github_issue_number` no longer aborts under macOS bash 3.2** (#1871): the helper in `workflow-lib.sh` expanded its `doc_files` array unguarded, which is an unbound-variable error under `set -u` in bash 3.2 when a development folder has no markdown files. The expansion is now guarded, so `test-framework-mode-type-routing.sh` gives the same pass/fail counts under `/bin/bash` 3.2 and bash 5.
