- **Worktree branches no longer track the integration branch** (#1593): the documented `git worktree add` recipe branched from a remote-tracking ref without `--no-track`, so the new branch's upstream was `develop`. A later bare `git push` was then either silently refused — a multi-line refusal that shell-output filtering can truncate to nothing, leaving a pull request on a stale head — or, with `push.default` set to `upstream` or `tracking`, wrote feature commits straight onto the integration branch, bypassing review entirely. The recipe now suppresses tracking, the protocols verify the branch's upstream immediately after entering a worktree, and every documented branch push uses an explicit refspec and confirms the remote head matches local.
