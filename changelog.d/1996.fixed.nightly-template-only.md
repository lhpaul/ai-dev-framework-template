- **Workflow-test nightly is template-only by default** (#1996): product repositories that sync `.github/workflows/workflow-tests.yml` no longer start the scheduled full harness unless they set the Actions repository variable `WORKFLOW_TESTS_NIGHTLY_ENABLED` to a value that compares equal to `true` under GitHub Actions' case-insensitive `==` (`true` / `True` / `TRUE`); any other value or absence keeps the nightly off. The public template repository still runs the nightly.
