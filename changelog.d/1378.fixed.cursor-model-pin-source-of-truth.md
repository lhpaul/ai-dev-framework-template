- **Cursor stage-agent models now come from the repository's own `.cursor/agents/*.md` pins** (#1378): `agent-model-config.md` states that each `.cursor/agents/<agent>.md` `model:` field is authoritative for Cursor runs, and that the "Cursor model defaults (template)" table is only a starting point. The Cursor dispatch-profile contract and the `/run-item` and item-orchestrator surfaces now tell the dispatching context to read that pin before dispatching a stage subagent, and to honor downstream pins such as Grok or Composer as written, instead of choosing a model from the template tables.
