- **HTML-only inline code with quoted attributes is no longer escalated** (#1979): `html_markup_only()` in `pr-agent-runtime.py` split tags at any `<` or `>`, so a quoted attribute value such as `title="</summary>"` or `title="<!-- literal -->"` broke HTML-only recognition and a complete inline span in an admitted producer summary returned `escalate`. Tag recognition now honors single- and double-quoted attribute boundaries. Unterminated or mismatched quotes, prose mixed with HTML, unsupported raw wrappers, incomplete delimiters and invalid markup outside code still escalate. Regression coverage in `tests/test_pr_agent_runtime.py` and `tests/test-pr-review-loop-pr-agent-coderabbit.sh`.
