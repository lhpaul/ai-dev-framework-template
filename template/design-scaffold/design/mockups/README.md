## Framework

This folder holds the HTML mockups of the design tree.

- **Monorepo apps** and **Knowledge repo**: one folder per app,
  `<app>/` (the scaffold ships `example-app/` as a placeholder to rename).
- **Single app**: put the mockups directly in this folder and remove the
  per-app folders.
- Use one of these layouts per repository; do not mix them.
- `shared/` is reserved for shared viewer assets, delivered by a later
  framework item; keep it.
- Structure (folder names, headings, identifiers) is in English; mockup
  content is in the product's language.

Keep this Framework section unchanged; write the screen inventory in the
Project section below. The contract is
`docs/workflow/development-workflow/mockup-framework.md` in the AI Development
Framework template.
